# Ultimate Tic-Tac-Toe

A single-file web game (`index.html`, no build step). Play it on GitHub Pages at
https://beroe.github.io/ultimate-tictac/

## Rules
- The board is a 3×3 grid of small tic-tac-toe boards. X moves first.
- The square you pick inside a small board sends your opponent to the matching small board (highlighted in yellow).
- Three in a row wins a small board; three won boards in a row wins the game.
- If you're sent to a board that is already won or full, you may play in any open board.

Includes undo, new game, and auto-saves the game in the browser.
